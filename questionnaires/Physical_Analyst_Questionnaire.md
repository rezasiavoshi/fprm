# Physical Lab Analyst Questionnaire

**Analyst edition** of the *QC Laboratory Capacity, Staffing Gap and CAPEX Assessment*.

- **Area:** QC Physical Laboratory — finished products (release, stability, in-process checks)
- **Who fills it:** each analyst running physical tests (2–3 people, one copy each)
- **Working file:** `Physical_Analyst_Questionnaire.xlsx` — the tables are only in the workbook; this page lists the questions and explains the sheets.

## How the answers are used

Your answers give the time each test takes and how many samples arrive, which shows how busy the lab and its instruments are and whether more staff or instruments are needed. Times are asked as minimum / most likely / maximum, and hands-on analyst time is kept apart from unattended instrument time. Do not insert, delete or reorder columns in the workbook.

## Workbook sheets

| Sheet | What to do |
|---|---|
| Guide | Rules, which sheets take new rows, and what every column means. |
| Questions | Answer sections A–E below. |
| Volumes | In-process checks per batch and units per check for each product; release and stability numbers if known. |
| Test catalog | Time each physical test once (10 tests: average weight, diameter, thickness, hardness, brittleness, friability, disintegration, in-process check at the machine, fill volume, spray weight per actuation). |
| Test times | 480 family × test rows, chosen by dosage form. |
| Extra tests | Add tests that are missing: raw-material (particle size, bulk / tapped density), packaging (dimensions, leak test), dissolution bath work. |

## Pre-filled data

- 107 products in 64 method families; dosage forms: 96 Tablet, 7 Capsule, 2 Sachet, 1 Nasal spray, 1 not stated.
- Families group strengths that share methods, so times are asked once per family, not per product.
- If one tablet tester measures weight, thickness, diameter and hardness in one run, the run is timed once (on hardness).
- Assay, dissolution finish, water and pH are on the Chemical lab questionnaires; microbial tests on the Micro lab questionnaire.
- There is no recorded time catalogue for physical tests; every time on this questionnaire is a new estimate.

### Physical tests by dosage form

| Dosage form | Tests |
|---|---|
| Tablet | Average weight / uniformity of mass, Diameter (or length / width), Thickness, Hardness / breaking force, Brittleness, Friability, Disintegration, In-process check at the machine (one check, all its tests) |
| Capsule | Average weight / uniformity of mass, Disintegration, In-process check at the machine (one check, all its tests) |
| Sachet | Average weight / uniformity of mass, In-process check at the machine (one check, all its tests) |
| Nasal spray | Fill volume / deliverable volume, Spray weight per actuation (shot weight) |
